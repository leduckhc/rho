# Tests a commit message names, and that were deliberately removed.
#
# `bench/check-claimed-tests.py` asserts that every test a commit names exists in the tree. A
# commit that removes a test names it too, and the guard cannot tell the two apart from the
# words alone. So a removal is recorded here, with the commit that did it and the reason.
#
# One entry per physical line: <test_name> <commit-hash> <reason>. The parser is strict. It
# reads the first token as the test name and the second as a real hex commit, and it fails
# loudly on any line it cannot parse. A continuation line that began with a real test name
# would otherwise exempt that test from the guard forever, which is the loss this file exists
# to stop. Keep each reason on the same line as its name. Verify a hash with
# `git log -S"fn <name>"` before you write it.
