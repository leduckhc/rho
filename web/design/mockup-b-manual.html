rho is the harness, unbundled.

A composable coding agent harness, written in Rust. The agent loop, the providers, the tools, and the interfaces are separate crates. You take the parts you want.

$ cargo install --git https://github.com/leduckhc/rho rho-cli

1Why rho exists

Agent harnesses are heavy. One session can cost more than 100 MB of resident memory. That cost makes many parallel sessions impractical.

rho treats memory and start time as product features. rho never claims a performance win without a measurement and the command that produced it.

2The parts

Ten small crates. No crate depends on a frontend. Providers are cargo features. Replace any part with your own crate.

4How you extend it

Two tiers. Both work without a fork.

Tier 1, compiled. Implement the Provider, Tool, or Hook trait in your own crate. Link it into your build. Zero overhead.

Tier 2, out of process. Ship a plugin as a subprocess over stdio JSON-RPC. Write it in any language. A crashed plugin does not take down the session.
