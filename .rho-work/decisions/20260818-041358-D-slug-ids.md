# D-slug-ids — An artifact is named by a timestamp and a slug, never by a counter

**Question (owner, sprint 2):** spec ids, feature ids, and decision ids clashed, and the
clash got worse with every parallel worktree. What replaces the counter?

**Decision:** An artifact carries a creation timestamp in its file name and a slug as its
reference.

| Kind | File | Reference |
| --- | --- | --- |
| Spec | `docs/specs/<yyyymmdd-hhmmss>-SPEC-<slug>.md` | `SPEC-<slug>` |
| ADR | `docs/adr/<yyyymmdd-hhmmss>-ADR-<slug>.md` | `ADR-<slug>` |
| Decision | `.rho-work/decisions/<yyyymmdd-hhmmss>-D-<slug>.md` | `D-<slug>` |
| Feature | one row in `docs/features.md` | `F-<slug>` |

One decision is one file. `.rho-work/DECISIONS.md` is gone, and an index replaces it.
`docs/ids.md` maps every old numeric id, permanently, because the commit history names
them. `bench/check-ids.py` fails on a numeric id, on a reference that resolves to nothing,
and on a duplicate slug.

**Reason:** Two clash mechanics needed two different fixes.

A counter needs a central allocator. Two worktrees each take the next number, and both are
right until they merge. A timestamp needs no allocator, and it sorts by age.

A shared append-only file conflicts on every entry. All 62 decisions lived in one 1408-line
file, and in one stage of this sprint an architect appended nine entries while the
controller appended one, to the same file. One file per decision removes the conflict
completely.

A slug also removes a lookup. An old numeric decision id told a reader nothing, and
`D-plugin-does-not-classify-itself` states the rule it carries.

**What it cost.** 21 files moved, 62 decisions split, and 1208 references rewritten across
139 files, by `tools/migrate-ids.py`. The migration ran first in a throwaway worktree, and
the diff was read there before the main tree changed.

**What it found.** The catalogue listed two features twice. Two rows in the tier-2 table
restated two rows above them, one for the lifecycle hook points and one for the slash
commands. A numeric id hid the duplication, and a slug turned it into a collision that the
guard refused. So the catalogue holds 116 features now, and it held 118 before.
`docs/ids.md` records which old ids merged.

**Rules out:** A numeric artifact id. A shared append-only decision file. A reference that
needs a lookup table to read. A new artifact that waits for anybody to allocate a number.
