# D-fx-is-prior-art — fx joins pi and jcode as read prior art


**Question (controller):** fx is a Zig coding agent from Vercel Labs. Does rho read it as
prior art, and where does the reading get recorded?

**Decision:** Yes. `docs/comparison.md` gains a `## From fx` section, in the same table
shape as the pi and jcode sections. The source is read, not the docs alone. The clone
used was `https://github.com/vercel-labs/fx.git` at depth 1, sampled 21 August 2026.

**Reason:** fx solves the same problem rho solves, under the same constraint. It is a
small native binary with a small system prompt and a large tool set. It is Apache-2.0, so
the source is readable. AGENTS.md step 1 says to read the real source. The docs describe
`run_command`, and the source ships a `terminal` tool instead. Reading the docs alone
would have recorded a tool that no longer exists.

**What the reading is for:** rho copies an idea and its reason. rho does not copy Zig
code, and rho does not copy a design that costs footprint.

**Rules out:** treating the fx website as the source of truth. Adding an fx feature to
`docs/features.md` without a row that says who owns it and how a third party replaces it.
Claiming an fx number as a rho number. Every fx number on this page is attributed to fx.
