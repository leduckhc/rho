rho TUI — direction C · Column, the aligned ledger

The thesis: an agent transcript is tabular data, so rho renders it as a table. Every event takes one ledger row: glyph, verb, target, meta, duration. The verb column is five cells wide at every terminal width. A long target elides in the middle, so the filename stays visible. Spacer rows are cut, so more of the turn fits the same band. The colours are the six theme roles as theme.rs resolves them: muted 245, accent 78, error 203, warn 179, caution 173. Above the rule the terminal owns the text. Below it rho owns a fixed band.
